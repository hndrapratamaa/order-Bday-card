# Happy Birthday — Iqlima Ayuningtyas

Customized birthday microsite based on the original `happyBirthday-main` project.

## Included
- Indonesian + English birthday message
- Cream paper texture background
- Supplied couple photo, cropped for the photo frame
- Original-style birthday animation flow
- Balloon animation
- `Photograph — Keenan Tee` music slot

## Music
For copyright reasons, the ZIP does not contain the commercial song audio.
Place your legally obtained audio file here:

`music/photograph.mp3`

The page uses audible autoplay and immediately retries on the first tap/click if the browser blocks autoplay.

## Run
Open `index.html` directly, or serve the folder with any simple local web server.

## Age
The page currently follows the latest supplied text and uses **23**.
If the correct age is 25, replace:
- `23rd` → `25th`
- `23` → `25`
in `index.html`.
